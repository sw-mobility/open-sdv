# Vehicle Signal Bridge

> 이 페이지는 카탈로그 기능 확인을 위한 더미 프로젝트입니다.

차량 신호를 애플리케이션이 사용하기 쉬운 인터페이스로 노출하는 변환 계층입니다. 동일한 신호 이름과 단위를 유지하면서 차량 내부와 클라우드 사이의 통합 비용을 낮추는 예시를 보여줍니다.

## 제공 인터페이스

- 저지연 차량 내부 통신용 gRPC
- 엣지·클라우드 브리지용 MQTT
- 개발 및 진단용 REST API

## 설계 원칙

원본 신호의 출처, 단위, 갱신 주기와 접근 정책을 메타데이터로 함께 전달합니다. 소비자는 전송 프로토콜이 달라져도 같은 의미의 신호를 사용할 수 있습니다.
