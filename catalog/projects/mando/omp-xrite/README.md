# OMP_Xrite

## 프로젝트 소개

TI TDA4VM 기반 보드를 대상으로 하는 Yocto 레이어와 플랫폼 소프트웨어를 제공합니다.

## 설치 및 사용

공식 README에서 TI Yocto SDK 다운로드, 빌드 환경 설정, MACHINE 설정 및 meta-edgeai 레이어 적용 방법을 확인할 수 있습니다.

[공식 저장소에서 README 확인](https://github.com/sw-mobility/OMP_Xrite#readme)

## 참여 및 기여

기여 절차와 문의 경로는 공식 저장소의 안내를 확인하세요. 담당기관은 이 문서에 설치 방법, 사용 예제, 지원 환경과 기여 안내를 추가할 수 있습니다.

## 정보 출처

담당기관은 공동 프로젝트 목록을 기준으로 연결했습니다. 소개는 공식 저장소의 공개 README를 바탕으로 요약했습니다.
