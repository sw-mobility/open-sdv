# TANGO SDV

TANGO는 데이터 준비부터 신경망 생성, 대상 장치 최적화, 배포까지 연결하는 오픈소스 머신러닝 프레임워크입니다. 이 카탈로그에서는 SDV 환경에서 활용 가능한 공개 소프트웨어의 예시로 소개합니다.

## 해결하려는 문제

차량용 AI를 개발할 때 모델 선택, 학습, 변환, 대상 하드웨어별 최적화와 배포가 서로 다른 도구로 분리됩니다. TANGO는 이 흐름을 하나의 프로젝트 단위로 연결하는 것을 목표로 합니다.

## 주요 기능

- 데이터 라벨링과 학습 데이터 관리
- 자동 신경망 생성과 하이퍼파라미터 최적화
- ONNX, TensorFlow Lite, TensorRT 등 대상 런타임 변환
- 클라우드, Kubernetes, 온디바이스 배포 흐름
- 서비스 단위로 분리된 컨테이너 기반 구성

## 빠른 시작

```bash
git clone https://github.com/sw-mobility/TANGO-SDV.git
cd TANGO-SDV
make run
```

## SDV 아키텍처에서의 위치

TANGO는 개발 도구 계층과 차량·엣지 배포 계층 사이를 연결합니다. 모델을 생성하는 단계뿐 아니라 실제 대상 장치에 맞는 실행 산출물을 만드는 과정까지 다룹니다.
