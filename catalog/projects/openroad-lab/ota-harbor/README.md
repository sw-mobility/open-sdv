# OTA Harbor

> 이 페이지는 카탈로그 기능 확인을 위한 더미 프로젝트입니다.

OTA Harbor는 차량 소프트웨어 업데이트를 단순 파일 전송이 아니라 검증 가능한 릴리스 과정으로 다루는 예시 프로젝트입니다.

## 파이프라인

1. 빌드 산출물과 SBOM 생성
2. 릴리스 서명과 정책 검사
3. 시험 차량군 배포
4. 상태 지표 기반 확대 또는 중단
5. 실패 조건 충족 시 이전 버전으로 롤백

## 안전 고려사항

업데이트 정책과 차량 측 적용 정책을 분리합니다. 네트워크가 끊기거나 전원이 불안정한 경우에도 마지막으로 검증된 버전을 유지하도록 설계합니다.
