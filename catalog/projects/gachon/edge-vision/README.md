# Edge_Vision

## 프로젝트 소개

Jetson 계열 엣지 장치에서 경량 AI 모델을 실행·최적화하는 프로젝트입니다. NAS, Pruning, Quantization 및 YOLO 계열 모델의 추론 방법을 다룹니다.
